# エディター改善 実装記録（2026-11-15）

## 対象範囲

レビュー第一〜第五段階として、章単位のMarkdown出力境界、共通エクスプローラー、項目間の移動・タブ・カーソル復元・固定資料表示、大量項目向けの保存検索と一括整理、独立整理フォルダー、制作前チェックと制作状態を改善した。第四段階でschemaVersion 4、第五段階で5へ加算移行し、既存本文・ID参照・グラフ座標・アウトライン順を保持する。

## 変更点

- 章出力は、選択項目より後に現れる「同じ深さ、またはより浅い」アウトライン項目で終了する。選択章の子孫を含み、次章・上位章の本文を含めない。
- 執筆画面とグラフ画面で同じノードエクスプローラーを使用する。ノード名・本文・タイプ・タグの検索、タイプ／タグ絞り込み、階層表示、全折りたたみ、操作メニュー、名称変更、同階層の並べ替えを提供する。
- 設定資料一覧に共通の行表示と選択・フォーカス・操作メニューを適用し、名称・カテゴリ・別名・タグ検索、カテゴリ／タグ絞り込み、並べ替えに対応する。
- ノード行のチェックボックスをなくし、選択中の行を背景色で示す。グラフの複数選択はCtrl/⌘クリックまたは行メニューで行い、グループ化操作を維持する。
- プロジェクトごとの表示設定はlocalStorageへ分離して保存する。ノード一覧は幅・選択・折りたたみ・スクロール・検索・タイプ／タグ絞り込み、設定資料一覧は幅・選択・スクロール・検索・カテゴリ／タグ絞り込みを復元する。
- 検索中だけ一致項目の祖先を展開し、手動の折りたたみ状態は変更しない。検索や外部から指定された項目を表示する際は、競合する絞り込みを解除して祖先を展開し、選択行へスクロールする。
- Ctrl/⌘+Kの横断検索は40件ずつ表示し、続きがある場合は追加表示できる。IME変換中のEnterでは結果を開かない。
- ドメインの検索処理ではタイプ名・タグ名も検索し、ノード本文検索に必要なデータを検索対象外のノード分まで構築しない。
- アウトライン項目削除時、直下の子項目を削除項目の順序位置へ昇格するよう修正。既存の章出力順テストで見つかった回帰を防止する。
- ノードと設定資料をプレビュー／固定タブで開き、タブから閉じる・固定する・切り替える操作を追加。前後移動は現在セッション内の履歴で行い、検索・内部参照・グラフから開いた項目も履歴へ記録する。
- 本文エディタごとの選択位置を文書ID単位で保存し、再度開いたときに範囲内へ調整して復元する。保存失敗や不正値は無視し、編集を止めない。
- 設定資料画面から資料を執筆画面横へ固定できるようにした。表示内容は資料名・カテゴリ・別名・タグ・説明で、固定状態はプロジェクト別に保持する。小画面では本文の下に配置する。
- ノード一覧でCtrl/⌘クリック、Ctrl/⌘+Space、または行メニューから複数ノードを選択できる。選択状態はプロジェクト別の表示設定に保存し、削除済みIDを読み込み時に除く。
- 複数ノードへのタグ追加・削除と、トップ階層または既存グループへの一括移動を追加。選択した親子の重複移動と循環を防ぎ、所属変更ではグラフ座標・アウトライン順を維持する。
- 一覧の検索・タイプ・タグ条件を名前付きで保存し、呼び出し・削除できる。条件は最大30件で、プロジェクト別localStorageに保持する。作品データJSONの形式は変えない。
- 整理フォルダーをSnapshot v4の独立モデルとして追加。階層の作成、名称変更、削除、複数ノードの一括所属、フォルダー絞り込みに対応し、ノードのグラフグループとアウトライン出力順は変更しない。
- v1〜v3のJSONは検証済みの加算移行で読み込む。v3からは空のフォルダー一覧だけを追加し、本文や既存IDは変更しない。フォルダーID、親ID、ノードID、循環、重複所属を検証する。
- 整理フォルダー削除時は中のノードを削除しない。親フォルダーがあればノードをそこへ移し、子フォルダーを一段上へ昇格する。トップ階層ならノードを未整理にし、子フォルダーはトップ階層へ昇格する。ノード削除時はフォルダーの参照IDを整理する。
- フォルダー絞り込みは現在の一覧状態としてプロジェクト別localStorageへ保存し、検索条件と一緒に保存検索へ含める。存在しないフォルダーIDは全ノード表示へ正規化する。書き込み失敗は作品編集に影響しない。
- ノードに「下書き・要確認・完成」の制作状態を追加し、執筆画面とグラフの詳細欄で変更できるようにした。エクスプローラーにも状態名を表示する。v4以前のノードはv5移行時に下書きとなる。
- アウトライン・出力画面に制作前チェックを追加し、アウトライン未配置、空タイトル、空本文、要確認、本文／カスタム項目のリンク切れを一覧表示する。ノード／資料へのリンクから対象を開ける。
- アウトラインがある作品では、未配置ノードを標準全文出力から引き続き除外する。出力前にチェックした場合のみ、専用節へ追加する。KP情報の除外設定はそのまま適用する。指定章出力と設定資料集には未配置ノード選択を適用しない。

## 表示状態の保持範囲

| 状態 | 保存先 | 再読み込み後 |
| --- | --- | --- |
| ノード一覧の幅・選択・折りたたみ・スクロール・検索・タイプ／タグ条件 | プロジェクト別localStorage | 復元 |
| 設定資料一覧の幅・選択・スクロール・検索・カテゴリ／タグ条件 | プロジェクト別localStorage | 復元 |
| 開いている項目タブ・固定中の資料・本文カーソル位置 | プロジェクト別localStorage | 復元 |
| ノード複数選択・保存検索条件 | プロジェクト別localStorage | 復元。削除済みIDは除外 |
| 現在の整理フォルダー絞り込み | プロジェクト別localStorage | 復元。削除済みIDは全件表示へ戻す |
| 戻る／進むの移動履歴 | 現在の画面セッション | 復元しない |
| モバイルの画面タブ、集中執筆、グラフの複数選択・接続表示 | 現在の画面／編集セッション | 復元しない |
| シナリオ本文・ノード・接続・設定資料・アウトライン・整理フォルダー・制作状態 | IndexedDB／JSON schemaVersion 5 | 既存の自動保存・バックアップに従い復元。v1〜v4は追加項目のみ移行 |

不正な設定値・削除済みIDは既定値へ正規化する。ブラウザ保存領域の読み込み／書き込みが失敗しても、表示設定の復元だけを諦め、本文編集と自動保存は継続する。

## 再レビュー6件の修正（2026-11-15）

- 指定章出力では、現在のアウトラインに章IDが存在する場合だけプレビューと出力を有効化する。未選択・削除済みIDでは案内を表示し、Markdown/PDFの処理自体にもガードを置いた。Effectによる選択解除が実行される前の描画でも全文出力へ落ちない。
- 整理フォルダー削除は、残る各フォルダーと所属ID配列を複製してから、子の昇格・ノード所属の移動・兄弟順の調整を行う。入力snapshotは変更せず、グラフ座標・親グループ・アウトライン順は保持する。子フォルダーは削除位置へ挿入される順で昇格する。
- ノード一覧の上下・左右キーで開くボタンへフォーカスを移すようにし、Enterの標準ボタン操作で選択項目を開ける。IME変換中と入力欄内のキーは一覧操作で横取りしない。
- 「一覧で表示」は検索・タイプ・タグに加えてフォルダー絞り込みも解除し、祖先を展開して対象の描画後にスクロールする。同じ項目を開いたままでも表示操作を実行する。
- 検索に一致する項目を開く場合、保存対象の手動折りたたみ状態を変更しない。検索中の一時表示解除後に元の折りたたみが戻る。外部遷移で検索に一致しない項目を開く場合と、利用者が「一覧で表示」を明示した場合は、必要な祖先を展開する。
- 設定資料の行に安定IDを付け、外部遷移要求の番号を使って同一資料への再移動も検知する。絞り込みを外した後に対象行が描画されてから可視化する。削除済みIDではスクロール要求を残さない。
- 表示状態のlocalStorage保存形式、作品snapshot・schemaVersion・JSON入出力、本文・参照ID、グラフ、アウトライン、自動保存は変更していない。
