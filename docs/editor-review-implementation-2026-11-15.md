# エディター改善 実装記録（2026-11-15）

## 対象範囲

レビュー第一段階として、章単位のMarkdown出力境界と、執筆・グラフ・設定資料の一覧操作を改善した。プロジェクトデータの保存スキーマ、ノードID、`parentGroupId`、アウトライン順、グラフ座標、JSONバックアップ形式は変更していない。

## 変更点

- 章出力は、選択項目より後に現れる「同じ深さ、またはより浅い」アウトライン項目で終了する。選択章の子孫を含み、次章・上位章の本文を含めない。
- 執筆画面とグラフ画面で同じノードエクスプローラーを使用する。ノード名・本文・タイプ・タグの検索、タイプ／タグ絞り込み、階層表示、全折りたたみ、操作メニュー、名称変更、同階層の並べ替えを提供する。
- 設定資料一覧に共通の行表示と選択・フォーカス・操作メニューを適用し、名称・カテゴリ・別名・タグ検索、カテゴリ／タグ絞り込み、並べ替えに対応する。
- プロジェクトごとの表示設定はlocalStorageへ分離して保存する。ノード一覧は幅・選択・折りたたみ・スクロール・検索・タイプ／タグ絞り込み、設定資料一覧は幅・選択・スクロール・検索・カテゴリ／タグ絞り込みを復元する。
- 検索中だけ一致項目の祖先を展開し、手動の折りたたみ状態は変更しない。検索や外部から指定された項目を表示する際は、競合する絞り込みを解除して祖先を展開し、選択行へスクロールする。
- Ctrl/⌘+Kの横断検索は40件ずつ表示し、続きがある場合は追加表示できる。IME変換中のEnterでは結果を開かない。
- ドメインの検索処理ではタイプ名・タグ名も検索し、ノード本文検索に必要なデータを検索対象外のノード分まで構築しない。
- アウトライン項目削除時、直下の子項目を削除項目の順序位置へ昇格するよう修正。既存の章出力順テストで見つかった回帰を防止する。

## 表示状態の保持範囲

| 状態 | 保存先 | 再読み込み後 |
| --- | --- | --- |
| ノード一覧の幅・選択・折りたたみ・スクロール・検索・タイプ／タグ条件 | プロジェクト別localStorage | 復元 |
| 設定資料一覧の幅・選択・スクロール・検索・カテゴリ／タグ条件 | プロジェクト別localStorage | 復元 |
| モバイルの画面タブ、集中執筆、グラフの複数選択・接続表示、本文カーソル | 現在の画面／編集セッション | 復元しない |
| シナリオ本文・ノード・接続・設定資料・アウトライン | 既存のIndexedDB／JSON形式 | 既存の自動保存・バックアップに従い復元 |

不正な設定値・削除済みIDは既定値へ正規化する。ブラウザ保存領域の読み込み／書き込みが失敗しても、表示設定の復元だけを諦め、本文編集と自動保存は継続する。
