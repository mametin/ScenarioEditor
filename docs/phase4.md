# Phase 4 実装記録

## 実装

- `OutlineItem`は既存の独立モデルを維持。章・節を追加し、任意のノードを複数箇所から配置。同じ階層内の上下移動に対応。
- 章見出しの削除では子を親階層へ昇格し、ノード本文とグラフ座標は変更しない。
- 全文、指定章と配下、KP用、配布用（KP情報除外）、設定資料集をMarkdownでダウンロード。
- 正式名・別名・固定表記は保存済みID参照から出力時に解決。
- PDFボタンは日本語フォント候補・A4余白・章見出し改ページを設定した印刷用HTMLを新しいタブで開き、ブラウザ標準の「PDFに保存」を使う。日本語フォントの埋め込みは保証しない。

## 出力上の制限

PDFは専用PDFエンジンでの直接生成ではなく、ブラウザ印刷経由。初回はブラウザのポップアップ許可が必要な場合がある。PDF生成・ページ番号の挿入・フォント埋め込み、スクリーンリーダー向けPDFタグの実機確認は未実施。PDF出力の自動化E2Eも未実施。

Markdown対応: 見出し、太字、斜体、箇条書き、番号付きリスト、引用、区切り線、読み上げ/KPブロック、内部参照名。未対応の整形要素が将来追加された場合はこの出力変換とテストを更新する。

アウトライン未登録ノードがある場合、全体出力時はアウトライン登録項目のみ出力する。アウトラインが空の場合のみノード配列順の全文出力へフォールバックする。出力順序の自動補完はしない。
