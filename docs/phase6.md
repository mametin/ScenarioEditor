# Phase 6 実装記録

## 実装

- スマートフォンでは画面下部に「執筆・グラフ・設定資料・アウトライン」の主要ナビゲーションを固定。ホーム画面の小さいナビゲーション表示にも対応。
- 執筆画面を「本文」と「ノード一覧」に切り替え、タッチ向け操作サイズを確保。
- グラフ画面はノード一覧・グラフ・詳細を切替。グラフの接続ツールから種類を選び、一覧またはキャンバスで接続元・接続先を順番に選択できる。タッチではReact Flowのハンドル操作に加えて順次選択を使える。
- Web App Manifest、日本語名、テーマ色、SVGアイコンを追加。Service Workerは同一オリジンのアプリシェルと閲覧済みのJS/CSS/画像/フォントをキャッシュし、ネットワーク障害時にキャッシュ済みトップ画面を表示する。
- 旧キャッシュはバージョン更新時に削除。Next.js内部アセットと外部リクエストはキャッシュしない。
- GitHub同期はユーザーの判断により対象外。既存の画面は未実装と明示し、誤って同期済みと表示しない。
- GitHub Pagesの静的書き出しとGitHub Actions公開ワークフローを準備。プロジェクトリポジトリのサブパスと`username.github.io`のルートの両方でNext.jsの`basePath`を合わせる。ソースリポジトリはGitHub Pages上で公開するアプリファイルのためだけに使用し、シナリオJSONをコミットしない運用を案内。

## 制約

初回オンライン表示後、ブラウザのService Worker制御下になってから取得したアセットをキャッシュする。Next.js内部の生成チャンクはキャッシュしないため、すべての以前未訪問ルートがオフライン表示できる保証はない。まずオンラインで各画面を開いてからオフライン利用する。書き込みデータは引き続きIndexedDBへ保存する。

現時点で実機スマートフォンへのインストール、iOS/Androidブラウザのオフライン起動、再接続、ホーム画面アイコンを検証していない。Pagesのデプロイ先リポジトリもまだ接続されていないため、公開実行は未完了。実機と公開URLの最終確認をもってPhase 6の検証完了とする。
