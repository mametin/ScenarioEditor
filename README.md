# TRPG Scenario Editor

TRPGシナリオ執筆環境。現在は **Phase 6（モバイル対応・PWA）** まで実装しています。GitHub同期（Phase 5）は対象外です。各機能の範囲は [Phase 3記録](docs/phase3.md)、[Phase 4記録](docs/phase4.md)、[Phase 6記録](docs/phase6.md) を参照してください。

## 起動

Node.js 24系で動作確認済みです。

```sh
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。保存領域はブラウザとオリジンごとに異なります。`localhost` と `127.0.0.1` は別の保存領域です。

```sh
npm test
npm run typecheck
npm run build
npm start
```

## GitHub Pages公開

このアプリは静的書き出しに対応しており、サイト側のサーバーやGitHub認証は使いません。GitHub Pages対応プランのリポジトリにこのソースを置き、`main`へpushすると`.github/workflows/pages.yml`が`out/`を公開します。GitHub側のSettings → PagesでGitHub Actionsを公開元に選択してください。ワークフローが通常のリポジトリ名と`username.github.io`の両方のURLパスを設定します。

公開されるのはアプリのファイルです。GitHub PagesのWebサイトはインターネット上で公開されます。シナリオ本文をリポジトリにコミットする必要はありません。本文はブラウザ内に自動保存し、必要時にプロジェクトJSONをダウンロードしてご自身の端末に保管・再読み込みできます。異なる端末・ブラウザ間で自動共有はされません。ブラウザのサイトデータを消去する前にJSONを退避してください。

オフライン利用には最初にオンラインでページを開き、Service Workerがアプリと必要な静的ファイルをキャッシュするのを待ってください。閲覧済みの静的ファイルはキャッシュしますが、未アクセス画面やブラウザが期限切れにしたキャッシュはオフラインで開けない場合があります。

## 利用できる機能

- 日本語UIでのプロジェクト作成・一覧・切り替え、タイトルと構想メモの編集
- 500msのデバウンス自動保存、再読み込み後の復元
- IndexedDBへのトランザクション保存と過去リビジョンの復元
- 保存エラー表示、未保存内容のメモリ保持、再試行、未保存JSONのダウンロード
- JSONバックアップ、検証済みJSONを別プロジェクトとして復元（既存データを上書きしない）
- 複数タブの更新競合検出。競合時はJSONを退避してから再読み込み
- 独立したドメインモデル、スキーマ版検証、ID参照解決の基礎
- 画面幅に応じた表示と集中表示

構想メモはプロジェクトのプレーンテキスト属性です。シナリオ本文のリッチテキストエディタではありません。

## データを守るために

保存失敗時はページを閉じず、JSONを退避してください。メモリ保持はページのクラッシュや強制終了に耐える永続バックアップではありません。タブを離れる際に保存を試み、未保存時の通常の離脱にはブラウザ確認を要求しますが、OSによる終了は防げません。

ブラウザのサイトデータ削除・プライベートモード・容量不足・ストレージの自動削除に備え、定期的なJSONバックアップを推奨します。履歴は現時点で自動削除しません。全スナップショット方式のため長期利用の容量対策は後続課題です。

起動済み画面でのローカル編集はネットワーク通信に依存しません。ネットワークを切った状態でのアプリ起動・再読み込みを保証するPWAキャッシュはPhase 6で実装します。
