# TRPG Scenario Editor

TRPGシナリオ執筆環境。GitHub Pagesの静的サイトで動作し、作品は端末内へ自動保存します。Google Driveの手動JSON保存と、別Node.jsサービスを介したAI相談を追加しています。設定・制限・外部サービス公開手順は[Google Drive・AI連携ガイド](docs/google-drive-and-ai.md)を参照してください。

エディター改善レビューの第五段階として、整理フォルダーに加え、ノードの制作状態と出力前チェックを追加しました。詳細な保存・移行・検証内容は[実装記録](docs/editor-review-implementation-2026-11-15.md)を参照してください。

## 起動

Node.js 24系で動作確認済みです。

```sh
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。保存領域はブラウザとオリジンごとに異なります。`localhost` と `127.0.0.1` は別の保存領域です。

```sh
npm test
npm run test:ai
npm run typecheck
npm run build
npm start
```

AIサーバーをローカル起動する場合は、先に[連携ガイド](docs/google-drive-and-ai.md)の環境設定を行い、`npm run ai:dev`を別ターミナルで実行します。

## GitHub Pages公開

このアプリは静的書き出しに対応しており、Web画面自体はGitHub Pagesで公開できます。GitHub Pages対応リポジトリの`main`へpushすると`.github/workflows/pages.yml`が`out/`を公開します。Google Driveを使うには、Google Cloudの公開識別値をGitHub Actions Variablesへ設定して再ビルドします。サイト内AIを使うには、OpenAIキーを保持する別のNode.js APIサーバーを公開し、そのURLを同じくActions Variablesへ設定します。GitHub PagesだけではAI用サーバー処理を実行できません。

公開されるのはアプリのファイルです。シナリオ本文をアプリのソースリポジトリへコミットする必要はありません。本文はブラウザ内に自動保存されます。Google Driveへはファイルメニューから手動で開く・保存でき、JSONバックアップも引き続き使えます。Driveの自動同期は未実装です。ブラウザのサイトデータを消去する前にJSONまたはDriveへ退避してください。

オフライン利用には最初にオンラインでページを開き、Service Workerがアプリと必要な静的ファイルをキャッシュするのを待ってください。閲覧済みの静的ファイルはキャッシュしますが、未アクセス画面やブラウザが期限切れにしたキャッシュはオフラインで開けない場合があります。

## 利用できる機能

- 上部の「ファイル・編集・表示・シナリオ・ヘルプ」メニューから保存、JSON復元、検索、画面切り替え、タイプ・タグ管理、出力画面へアクセス。左の画面ナビは「表示」から再表示できます。メニューは矢印キー・Enter・Escに対応しています。

- 日本語UIでのプロジェクト作成・一覧・切り替え、タイトルと構想メモの編集
- 500msのデバウンス自動保存、再読み込み後の復元
- IndexedDBへのトランザクション保存と過去リビジョンの復元
- 保存エラー表示、未保存内容のメモリ保持、再試行、未保存JSONのダウンロード
- JSONバックアップ、検証済みJSONを別プロジェクトとして復元（既存データを上書きしない）
- Google Driveへの手動接続・PickerでのJSON読込・新規保存・既存ファイル保存・別名保存。Driveから開く作品は常に新しいローカルプロジェクトとして取り込む。認証情報は作品JSONに含めない
- AIへの選択本文・現在シーン・利用者が選んだ資料だけの相談。送信前確認、提案表示、未変更本文への選択範囲適用とUndo。OpenAI APIサーバーは別途設定が必要
- JSONダウンロード履歴の表示と、サイト全体のブラウザ保存領域の概算表示
- Ctrl/⌘+Kによるプロジェクト内横断検索（ノード本文・タグ・設定資料・別名）
- 執筆・グラフで共通のノードツリー。名前・本文・タイプ・タグ検索、階層折りたたみ、幅変更、ノード作成・名称変更・同階層並べ替え
- プロジェクト別のエクスプローラー状態復元（幅・選択・展開・スクロール・絞り込み）。設定資料一覧も検索・カテゴリ／タグ絞り込み・行メニュー・並べ替えを提供
- ノード一覧での複数選択、タグの一括追加・削除、既存グループ間の一括移動、プロジェクト別の保存検索
- ノード・設定資料のプレビュー／固定タブ、項目間の戻る・進む、本文カーソル位置の復元、執筆横に固定する設定資料パネル
- Ctrl/⌘+K横断検索は40件単位で続きの結果を表示。日本語IME変換中のEnterでは結果を開かない
- 複数タブの更新競合検出。競合時はJSONを退避してから再読み込み
- 独立したドメインモデル、スキーマ版検証、ID参照解決の基礎
- 接続タイプの名称・色設定。線と矢印先端へ同じ色を反映し、タイプ削除時は接続を安全に付け替え
- UI／本文フォントの個別設定、本文サイズ調整、テーマ色のコントラスト目安表示
- 保存状態と最終保存時刻の表示、選択中ナビゲーションの強調
- 画面幅に応じた表示と集中表示

構想メモはプロジェクトのプレーンテキスト属性です。シナリオ本文のリッチテキストエディタではありません。

## データを守るために

保存失敗時はページを閉じず、JSONを退避してください。メモリ保持はページのクラッシュや強制終了に耐える永続バックアップではありません。タブを離れる際に保存を試み、未保存時の通常の離脱にはブラウザ確認を要求しますが、OSによる終了は防げません。

ブラウザのサイトデータ削除・プライベートモード・容量不足・ストレージの自動削除に備え、定期的なJSONバックアップを推奨します。履歴は現時点で自動削除しません。全スナップショット方式のため長期利用の容量対策は後続課題です。

起動済み画面でのローカル編集はネットワーク通信に依存しません。Drive保存とAI相談は通信・設定が必要ですが、失敗時もローカル編集を妨げません。
